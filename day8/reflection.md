 # Course Reflection

The most difficult concept for me was asynchronous JavaScript. At first, I did not understand why my code printed `Promise {<pending>}` instead of the expected data. I gradually understood that `fetch()` returns a promise representing a future result, and that `await` pauses the execution of its async function while waiting for the result. Rebuilding the user directory assignment and observing requests in the browser's Network tab helped me understand how asynchronous operations work.

Based on the feedback I received on my capstone, I would improve the architecture diagram and explain cache invalidation more clearly. I would show the steps involved when new data is created or updated, including when cached data is refreshed or removed. This would make the design easier to understand and demonstrate how the system keeps information consistent.

Next, I want to build a working backend for QuickNotes using Node.js, Express, and PostgreSQL. This will help me turn my knowledge of APIs, databases, and system design into practical skills. After that, I plan to learn React so I can build more interactive user interfaces and connect them to backend services. I also want to practise testing and deploying applications to understand how software works beyond my local development environment.

Overall, the course has helped me appreciate the importance of writing reliable code and designing systems that can handle real-world demands.
